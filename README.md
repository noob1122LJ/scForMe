# scForMe

单细胞与空间转录组分析的个人资源索引（收藏资源库）。

A curated index of useful scRNA-seq / spatial transcriptomics tools, tutorials, and analysis resources. 本仓库只记录链接和短注，方便以后按主题往下加；测序数据、二进制和大体积文件留在原处。

## 已 Star

目前同步的是 GitHub 上已公开 Star 的仓库。新的 Star 按同样格式补在这一节。

| 仓库 | 链接 | 语言 | 说明 |
| --- | --- | --- | --- |
| Cthfudan/hcc | https://github.com/Cthfudan/hcc | R | 肝细胞癌（HCC）相关分析图脚本。根目录按图号分文件夹：`Fig1&S1-S3`、`Fig2&S4-S5`、`Fig3&S6-S7`、`Fig4&S8-S9`、`Fig5&S10`、`Fig6&S11`。官方 README 几乎为空，目前只有 `# hcc`。 |

主语言是 R，目录里另有部分 Python 脚本（例如 cell2location、细胞类型 landscape）。使用时直接看对应图文件夹里的脚本。
